# Mate Visual 🦉

App para el navegador para practicar **multiplicación y división** de forma visual, pensada para chicos de 8 años (estilo synthesis.is).

## Cómo usarla
**Jugar online:** https://maurogene.github.io/LuanCole/

O también: Descargá `mate-visual.html` y abrilo con doble clic en cualquier navegador. No necesita instalación ni internet.

## Qué tiene
- **Multiplicación con bloques:** arrastrás barras de cubos al tablero y se cuentan con animación.
- **División repartiendo:** repartís cubos entre amigos hasta que todos tengan lo mismo.
- **División agrupando:** armás grupos iguales hasta llegar al total.
- **Problemas de texto** para leer, elegir la operación y resolver.
- **Mapa de 12 niveles** que se desbloquean con estrellas, rangos por XP, rachas y puntaje.
- **Hojas para imprimir** con ejercicios visuales y hoja de respuestas.
- Funciona con mouse y pantalla táctil.
